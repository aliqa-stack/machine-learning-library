# Library Linear-Regeresion sederhana
 Implementasi rumus linear Algebra dan MSE
 Ini hanya untuk pembelajaraan dan latihan bukan untuk project serius! 

## Sebelum menjalankan program ini harap install terlebih dahulu compiler c++
```bash
    g++ //
```
## Pemakaian
```bash
git clone repository ini 
cd /folder-repository-clone
make -f MakeFile run
```
